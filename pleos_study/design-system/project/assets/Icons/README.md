# Icons

Pleos Connect system icons, copied as published in the Figma design assets and display guide. Single-ink SVGs filled `#131417` (`icon-primary`); `<img>` cannot recolour them, so on a dark surface recolour the fill when you embed them. Drawn on the Pleos 48px / 24-grid with round joins and caps.

- `ic_clock` — lap time card header.
- `ic_refresh` — 초기화 button.
- `ic_more`, `ic_plus`, `ic_arrow` (forward), `ic_arrow_left` (back), `ic_dropdown` — page navigation and menus.
- `ic_call` — reserved; the dashboard has no phone feature.
